# 16-bit RISC Processor
**September 2024 – December 2024**  
**ModelSim · Quartus · Verilog · Cyclone V FPGA · Assembly**

- Implemented a 5-stage, 16-bit Verilog RISC processor featuring multi-cycle control, read-write memory interface, branch handling, ALU, load/store operations, and condition flags
- Wrote ModelSim testbenches for over 100 assembly instructions, then synthesized on Quartus and uploaded to DE1-SoC FPGA to ensure functionality
- Optimized branch handling achieving a 2x mean speed up compared to baseline RISC Processor
