# mealSense
**August 2025 – Present**  
**Java · Spring Boot · Flutter · MongoDB · Gemini Live**

[mealsense.cc](https://mealsense.cc/)

- Engineered a meal planning app with recipe generation, inventory tracking, and an AI voice agent
- Built a scalable backend on Spring Boot and MongoDB with over 10k recipes, meal plans, and pantry tracking using R2 for pantry photos, OpenFoodFacts API for food barcode scanning, and Firebase Auth for login
- Implemented mapping features with Google Maps SDK and HERE API for nearby grocery/restaurant search, caching all locations in a MongoDB collection with text + category indexes for scalability and natural search
- Implemented a suggestion algorithm leveraging user-preference scoring for automated list generation
