# Smart Home IoT System
**December 2021 – Present**  
**ESP32 · C++ · ADC · I2C · MQTT · Docker · Linux · Home Assistant**

- Engineered breaker power monitor using ESP32, CT current clamps, and 16-bit ADC to measure split-phase AC power draw and track home energy consumption over Wi-Fi
- Built Wi-Fi enabled garage door controller/sensor using open-source ESPHome firmware, with bi-directional protobuf communication to self-hosted Home Assistant virtual machine
